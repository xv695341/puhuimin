# 🎂 蒲慧敏 · 生日祝福页

一个为好朋友量身定制的**纯前端生日惊喜网页**：打开是温暖的橙色调主页，生日当天可以解锁专属惊喜——满屏祝福卡片雨，随后自动播放烟花视频，配上星空与「生日快乐 / Happy Birthday」标题。

> “从今把定春风笑，且作人间长寿仙”

## ✨ 功能亮点

- **实时时间戳**：每秒刷新「你已经来到世界上 XX 天 XX 小时 XX 分 XX 秒」
- **生日倒计时**：自动计算距离 10 月 15 日生日还有多少天
- **惊喜彩蛋**：仅生日当天开放「点击打开惊喜」按钮（可加 `?preview` 参数随时预览）
- **祝福卡片雨**：60 条祝福语生成密密麻麻的漂浮卡片，从四面八方飞入铺满全屏
- **10 秒倒计时** → 无缝切换到烟花视频页（星空背景 + 霓虹标题）
- **移动端适配**：9:16 竖屏视频框、自适应卡片网格、安全区适配

## 🚀 在线访问

GitHub Pages 地址：`https://<你的用户名>.github.io/puhuimin/`

> 💡 惊喜按钮只在生日当天出现，平时想预览效果请在网址后加 `?preview`。

## 🛠️ 技术说明

- 无框架、无构建工具的原生 HTML/CSS/JS，开箱即用
- 字体：站酷快乐体 + Fredoka（loli.net 国内镜像，离线自动回退系统字体）
- 视频使用 `object-fit: cover` 裁切铺满 9:16 竖屏框，无黑边
- 卡片漂浮动画基于 CSS 自定义属性 + 随机参数，每张卡片轨迹独立
